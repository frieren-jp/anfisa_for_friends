# Анфиса для друзей

Восстановленный учебный Django-проект из чата Телемоста: каталог мороженого,
страницы сортов, страница о проекте и русская административная панель.

## Запуск в Windows

Откройте PowerShell в этой папке. Нужен Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
cd anfisa_for_friends
..\.venv\Scripts\python.exe manage.py migrate
..\.venv\Scripts\python.exe manage.py loaddata catalog.json
..\.venv\Scripts\python.exe manage.py createsuperuser
..\.venv\Scripts\python.exe manage.py runserver
```

Главная: http://127.0.0.1:8000/
Каталог: http://127.0.0.1:8000/ice_cream/
Админка: http://127.0.0.1:8000/admin/
Общий вход: http://127.0.0.1:8000/login/

Общая форма входа принимает аккаунты администратора и обычных пользователей.
После входа администратору доступны ссылки «Админка» и «Добавить мороженое».
Обычных пользователей можно создать в админке в разделе «Пользователи»,
не выдавая им статус персонала и суперпользователя. Саморегистрация не добавлена.
Общая форма входа добавлена по уточнению пользователя; сообщения от 28 сентября
явно требуют создания суперпользователя и входа через `/admin/`.

Вход в админку выполняется с собственным логином и паролем, созданными командой
`createsuperuser`. Чужие аккаунты из учебного дампа не перенесены.
Повторная загрузка `catalog.json` восстанавливает исходные записи по их ID,
поэтому не запускайте её после собственных правок каталога без необходимости.

## Проверка

Из папки `anfisa_for_friends`:

```powershell
..\.venv\Scripts\python.exe manage.py check
..\.venv\Scripts\python.exe manage.py test
```

В комплекте есть миграция и фикстура: 11 сортов, 2 категории, 7 топпингов,
4 обёртки. Неопубликованные сорта скрыты с публичных страниц.

из `DJANGO_SECRET_KEY`; без переменной создаётся временный ключ на время процесса
(после перезапуска потребуется повторный вход в админку).
